# Instalación

**Configuración → Galería de plugins → Texto para fabricación → Instalar.** NOPAL clona el repositorio en `plugins/font-library/`. Es un paquete completo (tipografías incluidas) y no requiere cambios en el core. No tiene backend, así que no hace falta reiniciar NOPAL.

Las tipografías pesan varios megabytes: el repositorio es considerablemente más grande que los demás plugins.
